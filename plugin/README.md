# Vyšľap si medailu – marketingový plugin

- `skills/vyslap-plan` – stratég: plán, kampane, súťaže, týždenný balík, report
- `skills/vyslap-obchod` – objednávky z webu, strážca medailí (`medaily.md`), pripomienka odoslania
- `skills/vyslap-reklama` – platená reklama (Meta), kreatívy, vyhodnotenie, mesačný report
- `skills/vyslap-obsah` – tvorca a správca: posty, carousely, stories, reels, publikovanie cez Metricool
  - `references/znacka.md` – profil značky (fakty, tón, zákazy) – jediný zdroj pravdy
  - `assets/vzory/` – Alexove publikované posty ako vzor štýlu
  - `scripts/render.py` – grafika (carousel/post/story), `scripts/reel.py` – animovaný reel, `scripts/nahraj.py` – nahranie médií pre Metricool

Závislosti: Python 3, Playwright + Chromium, Pillow, ffmpeg.
